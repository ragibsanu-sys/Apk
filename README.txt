THE CREATION Billing - Android project

Two easy ways to build the APK:

1) Android Studio (on a PC)
   - File > Open > select this folder
   - Wait for Gradle sync to finish
   - Build > Build APK(s)
   - APK: app/build/outputs/apk/debug/app-debug.apk

2) Without Android Studio (using GitHub)
   - Create a free GitHub account > New repository > upload all files of this folder
   - Actions tab > "Build APK" > Run workflow
   - After 3-5 minutes download the artifact TheCreation-Billing-APK (zip containing app-debug.apk)

When installing the APK, allow "Install from unknown sources".
To change the bill design/logic edit: app/src/main/assets/index.html
